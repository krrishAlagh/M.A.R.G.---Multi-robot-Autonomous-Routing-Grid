Project Reference

The application combines a React/Vite command-center interface, an Express REST and WebSocket backend, and an edge-to-cloud computer-vision pipeline documented in the repository.

System Research Summary

  • Edge sensing: synchronized camera streams on NVIDIA Jetson hardware run object detection, tracking, and OCR locally.
  • Telemetry: event-driven JSON and WebP/JPEG evidence is transmitted over MQTT or WebSocket rather than streaming raw video.
  • Cloud intelligence: Haversine-distance DBSCAN groups repeated detections into canonical defect clusters.
  • Decision support: traffic analytics and Gemini structured function calling help route validated incidents into municipal work orders.
  • Command center: dashboards expose live detections, maps, fleet activity, analytics, alerts, and cross-agency workflows.
